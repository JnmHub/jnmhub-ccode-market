# Output Contract（report.md 收尾契约）

`report.md` 是任务唯一的过程文档义务：任务完成（或明确终止）时，由执行者**直接编辑任务目录下的骨架**填充为完整报告。没有渲染器、没有门禁工具——验收人按本契约核对内容真实性（报告里的命令应可一键复跑）。

## 通用规则

- 文件名保持 `report.md`（小写），标题、正文、项目符号说明使用中文；只有代码、文件名、命令名、协议字段名、接口字段名保留原文
- 内容必须来自真实做过的事：未跑通就如实写未跑通与卡点，禁止空洞占位、禁止虚构过程
- 会话态 / cookie / token / storage 快照必须脱敏：只保留键名、长度、哈希、前后缀、过期时间等最小验证信息
- 收尾时删除骨架注释与提示行（`<!-- ... -->` 各行）
- 未核实文件真实存在前，不得写"已落盘"；未拿到最新验证结果前，不得写"已成功"

## 必填六节（骨架即格式）

1. **任务目标与结果**——一句话目标 + 最终验收状态：跑通的命令 + 实测输出摘要（贴真实输出，脱敏后）。若目标未完全达成，写明偏差：原目标哪些完成、哪些未完成、卡在哪。
2. **实现路径**——从输入样本到交付物的关键步骤顺序（定位→取证→还原→复现→验证），写清关键文件 / 断点 / 函数名 / 端点，让后来者能照着重走。
3. **逆向思路**——候选路线与选择依据、关键转折点、为什么放弃其它路线。失败路线的排除依据也是重要结论。
4. **难点与坑点**——卡壳处、错误尝试、环境坑、反调试/混淆/风控对抗细节；失败也如实写。
5. **经验沉淀**——可复用的方法 / 命令 / 判据 / 参数含义，下个同类任务可直接抄的结论；外部搜索的关键结论（query + URL + 对决策的影响）也收在本节。
6. **交付物与复现**——文件清单（相对路径 + 用途）+ 复现命令 + 依赖安装（如 `pip install pycryptodome`）+ 样例输入与预期输出片段（脱敏）。API 任务写完整请求（method / url / headers / body）与响应样本片段。

## 按专题补充（建议，非强制）

任务命中以下特征时，把对应要点写进「实现路径」/「难点与坑点」小节（而不是另开文件）：

- **签名链路**：sign field 与 carrier、参数归一化 / canonical string 拼法、nonce/timestamp 混入边界、算法家族与随机源
- **本地复现 / 纯算法**：算法输入清单与来源、密钥材料派生链、一组真实「输入→输出」样例、最小伪代码或数据流图（如 `ts+nonce+body → sort → HMAC(key) → base64 → X-Sign`）
- **补环境**：first divergence、失真面（api/descriptor/crypto/storage…）、存在性判定、最小补丁策略
- **JSVMP/VM**：VM boundary、dispatcher/handler table 定位结果、至少一条 `pc → opcode` 真实轨迹、未确认 handler 清单；黑盒复用路线写清 blackboxApi 与验收结果
- **WASM**：加载方式与 glue 类型、imports/exports 概要、关键线性内存边界；受保护时写 bypass 思路
- **媒体 DRM / 内容解密**：明确标注验证到了哪一层（容器可读 ≠ 流层无错 ≠ 内容层解密成功）、加密模式、密钥来源、EME 事件时间线
- **指纹 / 环境检测**：detector families、哪些指纹向量经变换进入签名/加密（algorithmInputs）、最小 override 面
- **验证码 / 挑战链**：challenge 类型与状态机、token carrier 与刷新、真实交互触发经验
- **反调试 / 反篡改**：模式清单、注入时机、已绕过与未解决模式
- **会话依赖**：凭证载体（cookie/storage/memory）、刷新与失效条件、是否需要用户协作

任务产物（脚本、trace、样本 JSON 等）放任务目录内任意位置（建议直接放任务目录或其 `run/` 子目录），在「交付物与复现」节列清单即可；不再要求固定的 `run/xxx-notes.md` 命名。

## 完成判据（文字红线）

- "已完成 / 已交付"只能在最终示例代码真实跑通（可独立运行、服务端实测成功）之后说
- 挑战链 / 验证码类任务的验收 = 端到端服务端返回成功，不是"格式被接受 / 字段齐全"
- 局部样本、单点成功、容器可读、浏览器偶发成功都不算验收
- 交付物 = 可运行示例 + report.md，不是口头宣称
