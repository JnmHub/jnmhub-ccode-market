这一页只做一件事：把「插件页能碰到什么」逐项打印出来。所有「拒绝」都是正确结果。

A · 桥暴露了什么（Object.keys(window.ccodePlugin)）

…
应当**只有** 5 个键：getInfo / getSettings / getTheme / readText / readDataText。 多出任何一个都说明 preload 被放宽了。

B · 沙箱里不该存在的东西

sandbox: true + contextIsolation: true + nodeIntegration: false 之后，以下对象在插件页主世界必须全部是 undefined。

C · 宿主渲染进程的对象也不可见

插件页与宿主渲染进程是两个 document。宿主挂在 window.ccode 上的一整套 桥（文件选择、远程会话、更新…）在这里必须取不到。
