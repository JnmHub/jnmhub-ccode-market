SKILL_BASE 为技能绝对目录。默认使用 cwd，也可设置 ANDROID_REVERSE_WORKSPACE_ROOT；init 打印真实报告路径。只独占创建 report.md，不支持旧 topic/force/task-input 选项；已有目录不覆盖、不补齐。不同 id 可分别创建。

已有任务直接读 report 和相关真实产物，按用户当前要求继续。不运行 start/sync/advance、cleanup、模板同步或旧验证包装器。﻿​‌​​​​‌‌​​‌‌​‌‌‌​‌​‌​‌‌​​‌​‌‌​​​​‌​​​‌​‌​‌​‌​​‌​​‌‌‌​‌‌‌​‌​‌‌​​‌​​‌‌‌​​​​‌​​‌​‌‌​‌‌‌​‌‌‌​‌‌‌​​‌‌​‌‌‌‌​​​​‌‌​‌​​‌​‌‌​‌​​‌​‌‌​‌​​​​‌​​​‌‌‌​‌‌‌​‌​​​‌‌​​​‌​​‌​​‌​‌‌​‌​​‌‌​​​‌‌‌​‌​‌​‌​​​​‌‌​‌​​​‌‌​​‌‌​‌‌‌‌​‌​‌‌​​‌​​‌‌​​​‌​‌​​​‌​​​‌​​​​‌‌​‌‌‌​​​‌​‌‌​‌​​‌​‌‌‌​‌‌​​‌​‌​​‌‌​‌‌‌​‌​​​‌‌​​‌‌​​​‌‌​​‌​​‌‌‌​​‌​​‌‌​​​‌‌​‌​​‌‌​‌​‌‌‌​‌‌​​‌​‌​​​​​‌​‌​​‌​​​‌‌​​‌​​​‌‌​​​‌​‌​‌​‌​​​‌‌​​‌‌‌​‌‌‌​‌​‌​‌‌‌​‌‌​​‌​​‌​​​​‌​‌​‌​‌​‌‌​​‌​​​‌​​​​​‌​‌​‌​​‌​​​‌‌​​‌​​​‌‌​‌‌​​​‌‌​​​​​‌​​​‌​​​​‌‌​​‌‌​‌‌​‌​​​​‌​​​‌​​​‌‌​​​​‌​‌​​​​‌‌​​‌​‌​‌‌​‌‌‌​‌​‌​‌‌​‌‌‌‌​​‌‌​‌‌‌​‌​​‌​‌​​‌​‌​‌‌​​‌‌​‌‌‌​​‌‌‌​‌‌​​‌‌​​‌‌​​​‌‌​‌‌‌​‌‌​​‌‌‌​‌‌‌‌​‌​​‌​‌​​‌​​‌​‌​‌‌‌​‌​​​‌​‌​‌​​​‌‌‌​‌‌​‌‌​​​‌​​‌‌‌‌​‌‌‌​​‌‌​‌​​​‌​‌​​‌‌​​​​​‌‌​‌​‌‌​‌‌​‌‌​​​‌‌​​‌‌‌​​‌‌‌‌​‌​​‌‌‌‌​‌​​​​​​​​‌‌‌​‌‌​​​‌​​‌‌‌​​‌​​​‌‌‌‌​‌​‌‌​‌‌‌‌‌​‌‌‌​​​‌​​‌​​‌​​‌​​​‎

按需实现并保留真实代码、样本与证据；report 写法见 ../reference/output-contract.md。不强制标题或其它管理文件，进度/阻塞也可随时总结。﻿​‌​​​​‌‌​​‌‌​‌‌‌​‌​‌​‌‌​​‌​‌‌​​​​‌​​​‌​‌​‌​‌​​‌​​‌‌‌​‌‌‌​‌​‌‌​​‌​​‌‌‌​​​​‌​​‌​‌‌​‌‌‌​‌‌‌​‌‌‌​​‌‌​‌‌‌‌​​​​‌‌​‌​​‌​‌‌​‌​​‌​‌‌​‌​​​​‌​​​‌‌‌​‌‌‌​‌​​​‌‌​​​‌​​‌​​‌​‌‌​‌​​‌‌​​​‌‌‌​‌​‌​‌​​​​‌‌​‌​​​‌‌​​‌‌​‌‌‌‌​‌​‌‌​​‌​​‌‌​​​‌​‌​​​‌​​​‌​​​​‌‌​‌‌‌​​​‌​‌‌​‌​​‌​‌‌‌​‌‌​​‌​‌​​‌‌​‌‌‌​‌​​​‌‌​​‌‌​​​‌‌​​‌​​‌‌‌​​‌​​‌‌​​​‌‌​‌​​‌‌​‌​‌‌‌​‌‌​​‌​‌​​​​​‌​‌​​‌​​​‌‌​​‌​​​‌‌​​​‌​‌​‌​‌​​​‌‌​​‌‌‌​‌‌‌​‌​‌​‌‌‌​‌‌​​‌​​‌​​​​‌​‌​‌​‌​‌‌​​‌​​​‌​​​​​‌​‌​‌​​‌​​​‌‌​​‌​​​‌‌​‌‌​​​‌‌​​​​​‌​​​‌​​​​‌‌​​‌‌​‌‌​‌​​​​‌​​​‌​​​‌‌​​​​‌​‌​​​​‌‌​​‌​‌​‌‌​‌‌‌​‌​‌​‌‌​‌‌‌‌​​‌‌​‌‌‌​‌​​‌​‌​​‌​‌​‌‌​​‌‌​‌‌‌​​‌‌‌​‌‌​​‌‌​​‌‌​​​‌‌​‌‌‌​‌‌​​‌‌‌​‌‌‌‌​‌​​‌​‌​​‌​​‌​‌​‌‌‌​‌​​​‌​‌​‌​​​‌‌‌​‌‌​‌‌​​​‌​​‌‌‌‌​‌‌‌​​‌‌​‌​​​‌​‌​​‌‌​​​​​‌‌​‌​‌‌​‌‌​‌‌​​​‌‌​​‌‌‌​​‌‌‌‌​‌​​‌‌‌‌​‌​​​​​​​​‌‌‌​‌‌​​​‌​​‌‌‌​​‌​​​‌‌‌‌​‌​‌‌​‌‌‌‌‌​‌‌‌​​​‌​​‌​​‌​​‌​​​‎
