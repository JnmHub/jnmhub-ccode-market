## 开始与恢复

在实际项目 cwd 中用绝对路径调用技能工具；不要为了调用工具切到技能目录创建任务。

```text
node <SKILL_BASE>/tools/task/task-init.mjs <task-id> --goal="目标" --boundary="边界"
```

可选参数只保留 goal/boundary。ANDROID_REVERSE_WORKSPACE_ROOT 未设置时用 cwd；输出显示实际落点。task-id 必须为正常单段名称，不能是路径、保留名或 _TEMPLATE。只新增 artifacts/tasks/<task-id>/report.md；不复制专题包、不补状态账本。﻿​‌​​​​‌‌​​‌‌​‌‌‌​‌​‌​‌‌​​‌​‌‌​​​​‌​​​‌​‌​‌​‌​​‌​​‌‌‌​‌‌‌​‌​‌‌​​‌​​‌‌‌​​​​‌​​‌​‌‌​‌‌‌​‌‌‌​‌‌‌​​‌‌​‌‌‌‌​​​​‌‌​‌​​‌​‌‌​‌​​‌​‌‌​‌​​​​‌​​​‌‌‌​‌‌‌​‌​​​‌‌​​​‌​​‌​​‌​‌‌​‌​​‌‌​​​‌‌‌​‌​‌​‌​​​​‌‌​‌​​​‌‌​​‌‌​‌‌‌‌​‌​‌‌​​‌​​‌‌​​​‌​‌​​​‌​​​‌​​​​‌‌​‌‌‌​​​‌​‌‌​‌​​‌​‌‌‌​‌‌​​‌​‌​​‌‌​‌‌‌​‌​​​‌‌​​‌‌​​​‌‌​​‌​​‌‌‌​​‌​​‌‌​​​‌‌​‌​​‌‌​‌​‌‌‌​‌‌​​‌​‌​​​​​‌​‌​​‌​​​‌‌​​‌​​​‌‌​​​‌​‌​‌​‌​​​‌‌​​‌‌‌​‌‌‌​‌​‌​‌‌‌​‌‌​​‌​​‌​​​​‌​‌​‌​‌​‌‌​​‌​​​‌​​​​​‌​‌​‌​​‌​​​‌‌​​‌​​​‌‌​‌‌​​​‌‌​​​​​‌​​​‌​​​​‌‌​​‌‌​‌‌​‌​​​​‌​​​‌​​​‌‌​​​​‌​‌​​​​‌‌​​‌​‌​‌‌​‌‌‌​‌​‌​‌‌​‌‌‌‌​​‌‌​‌‌‌​‌​​‌​‌​​‌​‌​‌‌​​‌‌​‌‌‌​​‌‌‌​‌‌​​‌‌​​‌‌​​​‌‌​‌‌‌​‌‌​​‌‌‌​‌‌‌‌​‌​​‌​‌​​‌​​‌​‌​‌‌‌​‌​​​‌​‌​‌​​​‌‌‌​‌‌​‌‌​​​‌​​‌‌‌‌​‌‌‌​​‌‌​‌​​​‌​‌​​‌‌​​​​​‌‌​‌​‌‌​‌‌​‌‌​​​‌‌​​‌‌‌​​‌‌‌‌​‌​​‌‌‌‌​‌​​​​​​​​‌‌‌​‌‌​​​‌​​‌‌‌​​‌​​​‌‌‌‌​‌​‌‌​‌‌‌‌‌​‌‌‌​​​‌​​‌​​‌​​‌​​​‎

已有目录（含空目录/半报告）创建失败且不修改。失败残目录保留，由用户检查或手动补 report，不自动删除。不同 id 不受历史任务阻断。

续跑：读已有 report 和本轮相关真实证据，按用户要求推进。不要运行已弃用的 start/sync/advance/cleanup、sync-template-layout 或旧任务验证/收口包装器，不执行旧 JSON 的命令字段。

## 包维护

`npm run test:task-lite` 执行 Node 内置离线文件行为回归；`npm run smoke` 包含 lite 与 maintenance 负例，`npm test` 串联 check 和 smoke，`npm run release:check` 调用同一测试链且不发布。证据默认写系统临时目录下 android-reverse-tests，可用 TASK_LITE_TEST_OUTPUT 指定项目外目录。不接真实设备/目标，不因退役占位缺失而恢复旧布局；包 QA 通过不证明目标能力。
