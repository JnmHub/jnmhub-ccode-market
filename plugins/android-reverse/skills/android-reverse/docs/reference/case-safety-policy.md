# Case Safety Policy

- 仅处理用户明确授权或训练/CTF/样本环境中的目标
- 不主动执行未授权漏洞利用、持久化、投递、横向移动
- 任何会改写真实设备状态、真实账号态或真实网络环境的动作，都必须记入 report 的边界/授权信息（新任务即 task-init `--boundary` 的内容，续跑时补充），不要求独立状态文件
- 结论必须可回指文件、函数、调用链、日志、hook 输出或其他原始证据
- 以下动态操作先说明影响并取得用户确认：清除应用数据/卸载重装、真实账号登录/支付/短信验证码、修改设备系统状态（刷机、启用系统级框架），以及影响目标之外应用、系统或网络的任何操作。只读观察类动态操作（Frida attach/hook 观察、抓包、本地重打包）不逐次确认，但记入 report 边界信息

本技能明确不覆盖：

- 普通 Android 开发
- 未授权漏洞利用
- iOS 逆向
