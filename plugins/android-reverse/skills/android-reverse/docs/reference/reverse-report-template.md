# Report 写作参考

不复制全专题空标题。短记录可以只有几段：用户要什么、做了什么及证据、还有什么未知。长任务按需要展开。

完整内容指引见 [output-contract.md](output-contract.md)：概览、思路、实现路径、难坑、防御/环境、调用链、试错、算法、资产/方法和成果例子均按用户相关性覆盖，可合并或省略无关项；不是机器标题校验。

例如（仅示意，非实测）：

> 目前仅收到需求，尚未执行。目标是说明输入文件的结构。下一步需要用户提供文件；没有设备验证结果。

实际报告引用自己的真实证据；不要把本例或模板内容当成果。无需另写 walkthrough、summary、覆盖清单或 N/A。
